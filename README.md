# JH CloudOps

A hands-on AWS Cloud Operations project exploring infrastructure automation, cost governance, monitoring, and optimisation.

## Overview

JH CloudOps is a personal engineering project focused on designing and building cloud infrastructure, with AWS Cost Governance as its initial focus.

This repository serves as a space for continuous learning, experimentation, and technical improvement through hands-on AWS and DevOps practices.
